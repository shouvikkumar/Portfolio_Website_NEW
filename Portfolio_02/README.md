# Portfolio — React + Tailwind CSS

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

- All text/content lives in `src/data.js` — edit there.
- Theme colours & animations: `tailwind.config.js`.
- Contact form is a demo (`setTimeout`). Wire it to EmailJS / Formspree in `src/components/Contact.jsx`.
